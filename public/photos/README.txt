PROJECT PHOTOS
==============

Drop a screenshot for each project here, using the EXACT filename below.
These show as the image on the left side of each project card.

Required files (PNG):

  inklink.png        -> InkLink (Tattoo Shop Directory)
  hsn.png            -> Holiday Sands North (Oceanfront Hotel Website)
  j2dev.png          -> J2 Development (Web Studio Site)
  castle-clicker.png -> Castle Clicker (Browser Incremental Game)
  somniary.png       -> Somniary (Dream Journal App)
  trivia-feev.png    -> feev.io Trivia (Multiplayer Trivia Platform)

Notes:
- Filenames are case-sensitive on Vercel. Keep them lowercase exactly as above.
- Recommended: landscape image, ~1200x800 (3:2). It's cropped to the
  top of the image, so put the most recognizable part up top.
- If you'd rather use .jpg, change the matching extension in
  src/data/projects.ts (the "screenshot:" line for that project).
- Until a file is dropped in, the card shows a styled placeholder
  instead of breaking.
